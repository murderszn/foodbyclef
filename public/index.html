Local model setup & connection

This app uses Ollama’s System One decision API. Start Ollama 0.35.1 or newer and install the model:

ollama pull clef-flash
ollama serve

If the Ollama Mac app is running, you don’t need ollama serve. The first ruling may take a little longer while the model loads.
